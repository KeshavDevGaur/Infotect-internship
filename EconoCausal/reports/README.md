# EconoCausal Reports

This directory contains daily progress reports and CSV outputs generated by the project notebooks.

## Day 1 — Dataset Inspection

- `day01_dataset_summary.csv`: Dataset dimensions, missing-value counts, and duplicate counts.

## Day 2 — Data Quality Analysis

- `day02_missing_values.csv`: Missing-value analysis.
- `day02_duplicate_analysis.csv`: Duplicate-record analysis.

## Day 3 — Dataset Relationship Validation

- `DAY3_REPORT.md`: Summary of Day 3 objectives, findings, and next steps.
- `day03_relationship_validation.csv`: Results of identifier and dataset relationship checks.
- `day03_training_structure.csv`: Training record counts and identifier uniqueness statistics.

## Key Day 3 Findings

- Training records: 78,369
- Unique training IDs: 78,369
- Unique campaigns: 18
- Unique coupons: 866
- Unique customers: 1,428
- Duplicate training IDs: 0
- Customer demographic match rate: 55.71%

## Usage

The CSV files contain analysis outputs generated by the corresponding notebooks. Review the notebooks for the code and methodology used to produce these results.

## Limitations

The reports describe exploratory data checks. They do not prove that promotional discounts have a causal effect on purchasing behavior.
