# EconoCausal: Dynamic Pricing via Double Machine Learning

## Project Overview
EconoCausal is a machine learning project that investigates
the causal effects of retail promotional campaigns on
customer purchasing behavior.

The project aims to estimate treatment effects and develop
budget-aware promotional offer allocation strategies.
